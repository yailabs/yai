## Ownership and design pressure

Recall is a disposable derived contract in existing memory/access ownership.
Historical source qualification and current disclosure remain in the shared
transactional reader; typed relations remain in graph::experience. W20 owns
mechanical assertion/contradiction/supersession derivation. W19/H19 BM25 and exact
vector access remain candidate mechanisms, never semantic resolution or authority.
No RecallStore, canonical owner, database or automatic W/context injection.

Exact anchors cannot be replaced by fuzzy neighbors. Query candidates are
separate from qualified relations. Resolution may include multiple disconnected
segments; no causal edge is invented to join them. A selected obsolete assertion
requires its qualified supersession/contradiction context or a bounded refusal,
not a silently current label. Current disclosure precedes all public scoring,
counts, reasons, source refs and topology. As-of qualification admits no later
knowledge. Source loss is incomplete backing, not source substitution.

The first baseline is deterministic exact/BM25 over requalified source-derived
documents. The current memory CLI's vector query path invokes an encoder; Recall
must not call it implicitly. Any vector candidate seam must consume explicit
same-profile query evidence, remain optional, and never turn fixture vectors into
external encoder qualification. No pseudo-embedding or model query planner.

## Implemented contract

`memory_hierarchy::recall` is a derived consumer of existing historical/graph,
W19/H19 and W20 contracts, not a new state owner. `RecallRequest` and `RecallTrace`
use `yai.recall_request.v1` / `yai.recall_trace.v1`. The LMDB authorized entrypoint
reuses the same read transaction, canonical prefix, immutable backing checks and
current Principal/Tenant/Participant disclosure as HistoricalSemanticView; no
second history engine or compilation cache. Original publication anchors are now
also checked for older disclosed policy bindings, not only the active binding.

Request identity includes Case, expected CURRENT generation, exact cut, requester,
normalized nonempty query, sorted/deduplicated required refs, bounds and version.
Equivalent generation/Transition coordinates normalize to the same cut. Trace
identity additionally binds scoped source/derivation/availability, current
disclosure, selected semantics and optional exact vector evidence. Timings are
outside identity; hidden whole-history hashes/ranks are not published. Stale
generation, wrong scope/profile/query, unknown cut and incompatible bounds refuse.

The result retains typed experience events, recording/observation coordinates,
policy current-at-cut versus historical posture, rebuilt mechanical W20
assertions and contradictions, typed qualified relations, independently selected
Episode slices/singletons, exact backing postures, reasons and omission/depth
diagnostics. Several disconnected segments are allowed: selection association
does not mint a causal relation. Occurrence time remains absent when the owner
has no qualified timestamp contract. An arbitrary timestamp inside result JSON
does not become event-time evidence.

Exact object/resource, Transition, disclosed Episode and assertion refs are
mandatory anchors. Missing and hidden refs share the existing unavailable
posture. An existing exact event whose original backing is missing may be
returned explicitly source-incomplete; neither a current file nor an index hit
substitutes for that original. Policy artifact/source/publication, owned content,
Transition and rebuilt W20 support references are inspectable.

### Discovery versus resolution

The deterministic product baseline uses existing BM25 over bounded typed event
labels and freshly derived W20 assertion documents. Raw policy documents, arbitrary
`causal_refs` and hidden intermediate identifiers are not search labels. Current
visibility is established before corpus statistics, ranking, counts and public
reasons. No implicit model or encoder call.

The optional ENGINE vector seam accepts an existing representation profile,
exact normalized query, pre-encoded vector and index evidence. Only embeddings
whose documents match freshly rebuilt scoped v2 assertions are admitted. Query,
profile/Tenant, dimension, source digest and duplicate checks fail closed. Hidden
or unrelated embeddings do not contribute ranks, corpus statistics or identity.
Stable round-robin merging preserves the total candidate bound; BM25 and cosine
scores are not treated as comparable authority. This is mechanical consumption
of explicit vector evidence, not semantic qualification of an encoder or a new
product embedding workflow.

Resolution closes exact backing and supersession/contradiction groups after
discovery. It expands qualified experience relations, never recording adjacency;
shared policy ancestors do not fan out into all unrelated governed operations.
Current-at-cut policy is retained for a selected lineage independently of rank.
W20 mechanical digest replacement differs from unresolved provider-claim conflict;
recency, majority and retrieval score decide neither truth nor replacement.

Default bounds: 16 candidates, 64 events, 128 relations, 16 segments, four hops
per discovery-seed group, 16,384 semantic units and 1 MiB output. Repeated
candidates do not re-root already expanded nodes. Validated ceilings
are 256 candidates/events, 1,024 relations, 64 segments, 16 hops, 262,144 units and
1 MiB. Semantic units are serialized-character accounting, NOT model tokens.
The source reader retains its separate 4,096-item / 16 MiB qualified-view profile.
An optional candidate plus necessary context is an atomic group: event-bound
overflow omits that group with a count. Exact anchors and required conflict/
replacement context cannot silently disappear. Remaining unit/byte/relation/
segment overflow refuses the whole result; there is no hidden truncation.

### Discontinuous trajectory and cost

The same query `retry`, with one exact current Decision anchor, addresses an
earlier permitted operation/read, changed policy and denied operation, and a
late provider claim. Two gaps contain 10,000 unrelated Participant control
Transitions each. Sixty-four visible near-spelling/same-resource operations are
distractors; they are not evidence of the required trajectory. The long source
contains 20,081 canonical Transitions, NOT 20,081 visible experience events or
100k semantic objects. Seventy-two events enter the scoped experience source in
both cases. This is a practical deterministic CI characterization, not universal
production scale or a learned semantic-similarity benchmark.

Raw BM25 returns three candidates: two operation labels and one claim assertion.
The current Decision is an explicit anchor, not an invented query-planner result.
Qualified resolution adds P1, D1, observation, P2 and D2 through exact backing and
relations. The resulting eight events have 14 typed relations and five segments;
all 64 unrelated operations are excluded. Exact graph relations alone do not
select the independently relevant late claim; raw retrieval alone does not
provide policy validity, Decision support or source closure. No false causal edge
connects disconnected segments. This demonstrates added semantics, not an
accuracy win over a competing retriever.
