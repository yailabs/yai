# YAI Foundation Recovery

Status: active program. This dossier is navigation and coverage evidence, not
canonical architecture and not a substitute for direct `yai-dev` inspection.

## Method

Every recovery wave repeats direct legacy archaeology, current-source
characterization, a semantic differential, the owner test, minimal
implementation, executable proof, rediff, isolated commit and publication.
Repository source/history overrides every row in this dossier.

Wave 8 started the program from published YAI SHA
`3403ecdd2a321b689e41d747cbeb9d9e7c58e5e1`. It reinspected the March 2026
governance intake pipeline, adjacent review/registry/workspace attach consumer,
later governance/law cutovers, neutral-sample cleanup and final drain residue.

## Wave-8 constitutional verdict

The independent owner is a canonical governance history in the existing LMDB
environment: immutable source/artifact objects plus append-only integrity-bound
lifecycle events. It is not a Case ledger, a derived index, a synthetic system
Case or a governance plane. `runtime_consumable` is a view of published and
deterministically qualified status; it is not authority or Case effectiveness.

The refounded implementation is stronger than the historical ingestion path
on content identity, reproducibility, immutability, failure behavior, storage
authority and tests. It intentionally supports only constrained JSON and three
typed fact families. Historical Markdown/YAML input, registries, overlays,
compliance planes, mutable candidate files and unauthenticated file review are
not ported.

Wave-8 implementation and full regression are green. Publication record:
`7ce67afee34a3dbe879c2e5bee945602492be70c`; verified as HEAD, origin/master and ls-remote.

## Hardening-8 verdict

H8 independently repeated direct `yai-dev` archaeology and recovered the
previously omitted source-origin distinction. Current lineage is
`owner_ref + policy_key`; declared versions cannot collide with changed bytes;
duplicate JSON keys and bounded-parser attacks fail before persistence;
validator state is re-derived; publication/supersession is owner-scoped,
transactional and concurrency-tested. A rebuildable current-lineage index does
not replace immutable artifacts/events as history.

The shared LMDB default increased from 16 MiB to a configurable 256 MiB with a
tested 256-source/max-payload catalog contract and explicit capacity failure.
The repository copy of this dossier is now the maintained GitHub-visible copy.
Policy binding, EffectivePolicy and authority remain absent.
