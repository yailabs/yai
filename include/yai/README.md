# C header source map

Authority: local navigation for the current C ABI. Canonical concept meanings
are owned by [`docs/reference/semantics.md`](../../docs/reference/semantics.md).

Headers here describe interfaces compiled by current C components and smoke
tests. Presence of a header does not prove product reachability, a source
owner, or target adoption. Several names—including Subject, CaseWorld,
CapabilityLease, broad RecordKind values, and model output as EffectReceipt—are
current compatibility vocabulary rather than refounded semantics.

Treat API compatibility as requiring a named consumer and test. Do not infer
future directories or authority from this header layout.
